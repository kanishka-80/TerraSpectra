# Data Quality Report

## Status
Pending inspection of an accessible real hyperspectral scene.

## Required evidence
- Source identifier and license
- Raster dimensions and band count
- CRS, transform and spatial bounds
- NoData and non-finite pixel assessment
- Constant and invalid band assessment
- Wavelength metadata
- Label provenance and verification

A raster passing technical checks is not automatically a disease dataset
or a model-ready training dataset.

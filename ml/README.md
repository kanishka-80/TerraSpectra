# TerraSpectra - ML & Data Engineering

## Objective
Build a reproducible hyperspectral data pipeline
for crop stress intelligence and disease-risk forecasting.

## Week 1 Scope
- Dataset research and selection
- Raster metadata inspection
- Data quality validation
- Spectral exploratory analysis
- Preprocessing and normalization
- Patch extraction
- Dataset loader preparation
- Label quality audit

## Candidate Data Sources
1. EnMAP
2. PRISMA
3. NASA EMIT
4. AVIRIS / AVIRIS-NG

## Initial Data Pipeline
Source Data
    -> Raster Inspection
    -> Quality Checks
    -> Spectral Analysis
    -> Preprocessing
    -> Patch Extraction
    -> Data Loader

## Important
No dataset is considered model-ready until
its metadata, quality, labels and access conditions
have been verified.

See docs/dataset/ for research notes.
